```python
import math
from typing import Iterable, Dict, Optional, Any

def summarize_decode_speeds(lines: Iterable[Any]) -> Dict[str, Optional[float]]:
    """
    Summarizes decoding speeds from a stream of log lines.
    
    Complexity:
    - Time: O(N) where N is the total number of characters across all lines.
    - Space: O(1) extra space (excluding the output dictionary).
    """
    count = 0
    min_tps = float('inf')
    max_tps = float('-inf')
    total_tps = 0.0

    for line in lines:
        if not isinstance(line, str):
            continue
        
        # Tokenize by whitespace
        tokens = line.split()
        kv_pairs = {}
        is_decode_event = False
        
        # Parse key=value pairs
        for token in tokens:
            if '=' not in token:
                continue
            
            key, val_str = token.split('=', 1)
            
            # Rule: Ignore lines with duplicate keys (even if values match)
            if key in kv_pairs:
                break
            
            if key == 'event' and val_str == 'decode':
                is_decode_event = True
            
            kv_pairs[key] = val_str

        # Validation Logic
        if not is_decode_event or 'tps' not in kv_pairs:
            continue
            
        try:
            tps_val = float(kv_pairs['tps'])
            
            # Rule: Must be finite, strictly positive, and not NaN/Inf
            if math.isfinite(tps_val) and tps_val > 0:
                count += 1
                total_tps += tps_val
                if tps_val < min_tps:
                    min_tps = tps_val
                if tps_val > max_tps:
                    max_tps = tps_val
        except ValueError:
            # Ignore malformed floats
            continue

    if count == 0:
        return {
            "count": 0,
            "min_tps": None,
            "max_tps": None,
            "avg_tps": None
        }

    return {
        "count": count,
        "min_tps": min_tps,
        "max_tps": max_tps,
        "avg_tps": round(total_tps / count, 3)
    }
```

### Technical Explanations

**Why naive substring matching is insufficient:**
1. **Contextual Integrity:** Using `if "event=decode" in line` would return `True` for a line like `message="event=decode_failed" event=generate tps=10`. The logic must ensure `event` is the specific key and `decode` is its specific value.
2. **Duplicate Key Handling:** Substring matching cannot easily detect if `tps` appears twice in one line (e.g., `tps=10 tps=20`). The requirements specify that duplicate keys with conflicting values (or even identical values) make the record malformed. A dictionary-based approach during parsing allows us to detect the first occurrence of a key and invalidate the record if the key appears again.
3. **Token Isolation:** Substring matching might capture `tps=10` inside a different field, such as `description="high tps=10"`. Splitting by whitespace and then by `=` ensures we only process actual key-value pairs.

**Empty-result policy:**
If no valid records are found, the function returns `None` for the numeric fields (`min_tps`, `max_tps`, `avg_tps`). This is a standard production pattern to avoid `ZeroDivisionError` or returning misleading values like `0.0` or `inf`, clearly signaling to the caller that no data was processed.
