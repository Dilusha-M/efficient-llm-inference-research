## Explanation and Analysis

### 1. Why Naive Substring Matching Fails

Naive substring matching (e.g., simply searching for `"tps="` and extracting the subsequent number) is highly brittle because it ignores the strict structural requirement of the input format.

*   **Event Misidentification:** If a line is `"tps=10.5 and event=decode"`, a naive search might incorrectly associate the `10.5` with `event=decode` even if the structure is semantically invalid for that specific line, or it might fail to distinguish between unrelated fields.
*   **Malformed Duplicates:** If a line is `"event=decode tps=10.5 tps=20.0"`, a naive approach might incorrectly count both `10.5` and `20.0` as valid records, even though the requirement states that a duplicate value implies malformation or that we should treat the record set uniquely. By explicitly parsing the key-value structure (`key=value`), we enforce the required relationship between the field name and its value.

### 2. Empty-Result Policy

The policy for returning `None` for min/max/avg when no valid records are found is crucial for statistical integrity.

*   **Min/Max:** If the set of valid data points is empty, there is no minimum or maximum value to report. Returning `None` is the mathematically sound choice, avoiding the insertion of sentinel values like $\infty$ or $-\infty$ which would skew results if the caller attempted to use them without checking the count.
*   **Average:** The arithmetic mean is undefined for an empty set. Returning `None` correctly signals that no average could be computed.
*   **Count:** The count is explicitly set to 0.

### 3. One-Pass Algorithm and Space Complexity

The implementation uses a single pass over the input iterable (`lines`).

*   **Space Complexity:** The algorithm only stores a few scalar variables (`min_tps`, `max_tps`, `count`, `total_tps`) and temporary variables within the loop. The space used is $O(1)$ auxiliary space, excluding the space required to store the input iterable itself. We do not store all parsed records, only the necessary aggregates.
