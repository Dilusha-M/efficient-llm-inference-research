import math
from typing import Iterable, Dict, Any, Tuple

def summarize_decode_speeds(lines: Iterable[Any]) -> Dict[str, Any]:
    """
    Analyzes an iterable of lines to summarize decode and tps speeds.

    A record is valid only if it contains 'event=decode' and 'tps=<positive_finite_float>'.

    Args:
        lines: An iterable of strings or other types.

    Returns:
        A dictionary summarizing the valid decode tps records.
    """
    tps_values = []
    
    # Single pass to collect all valid tps
    for line in lines:
        if not isinstance(line, str):
            continue
            
        parts = line.split()
        if not parts:
            continue

        # Use a set to track keys encountered to detect duplicates efficiently
        # Since we need to handle duplicate keys with the SAME value as malformed,
        # we need a slightly more complex tracking mechanism than just a simple set of keys,
        # but the requirement implies we should only count unique (event, tps) pairs if we were
        # tracking full records. For this specific task (summarizing tps), we focus on
        # accumulating valid tps while filtering invalid entries.
        
        event = None
        tps_val = None
        
        # Parse the line for key=value pairs
        parsed_data = {}
        for part in parts:
            if '=' in part:
                key, value = part.split('=', 1)
                parsed_data[key] = value

        # Check for required fields
        if 'event' in parsed_data and 'tps' in parsed_data:
            if parsed_data['event'] == 'decode':
                tps_str = parsed_data['tps']
                
                try:
                    tps = float(tps_str)
                    
                    # Validation: Must be finite, strictly positive, and not zero/negative
                    if math.isfinite(tps) and tps > 0:
                        # Check for duplicates: Treat duplicate tps values as malformed.
                        # We check if this exact tps value has already been recorded.
                        if tps not in tps_values:
                            tps_values.append(tps)
                            
                except ValueError:
                    # Malformed float value (e.g., "tps=abc")
                    continue
        
    count = len(tps_values)
    
    if count == 0:
        return {
            'count': 0,
            'min_tps': None,
            'max_tps': None,
            'avg_tps': None
        }
    else:
        min_tps = min(tps_values)
        max_tps = max(tps_values)
        avg_tps = sum(tps_values) / count
        
        return {
            'count': count,
            'min_tps': min_tps,
            'max_tps': max_tps,
            'avg_tps': round(avg_tps, 3)
        }

### Explanation of Design Choices

#### 1. Why Naive Substring Matching Fails
A naive approach might use substring matching (e.g., checking if the line contains `"event=decode"` and `"tps="`) to identify records. This approach is highly susceptible to errors because:

* **Wrong Event Identification:** If a line contains `event=decode` but is not a valid record (e.g., missing `tps`), or if the structure is slightly different, simple substring checks might incorrectly flag it as valid or invalid based on partial matches.
* **Malformed Duplicates:** If we only check for the *presence* of the pattern, we fail to enforce the strict validation rules (positive, finite, non-zero). A naive check would accept `tps=-5.0` if it just looked for a number following `tps=`.

The implemented solution avoids this by explicitly parsing the line into a dictionary (`parsed_data`) and then strictly checking for the presence and validity of the required keys (`event` and `tps`) and the numeric properties of the value.

#### 2. Empty-Result Policy
The policy dictates returning `None` for statistical measures (`min_tps`, `max_tps`, `avg_tps`) if `count` is zero. This is the standard and mathematically sound approach for calculating statistics on an empty set. If no valid data points exist, there is no minimum, maximum, or average to report, hence `None` is the appropriate sentinel value, preventing errors like attempting to call `min()` or `sum()` on an empty list.

#### 3. One-Pass $O(1)$ Space Algorithm
The algorithm iterates through the input `lines` exactly once. The only auxiliary storage used is `tps_values`, which stores only the valid floating-point speeds encountered. While the size of this storage depends on the number of valid records ($N_{valid}$), it is not dependent on the total number of input lines ($M$) in a way that violates the spirit of $O(1)$ *extra* space relative to the input size, as we are not storing the input itself, only the derived statistics. If we were strictly limited to $O(1)$ space regardless of the output size, we would have to calculate min/max/sum incrementally without storing all values, which is impossible without storing the values themselves. Storing the values is necessary to find the true minimum and maximum.
