### Task 3 — robust aggregation
**Conclusion:** The failed run should be recorded as `Failed: <timestamp>` in the stream, not treated as zero. The median is computed over successful runs.
**Assumptions:**
*   Pseudocode must be language-agnostic (e.g., Python, C++, Java).
*   The failed run's record must be preserved in the stream.
*   The calculation of the median involves only records that passed validation.
*   If fewer than 2 successful runs, the median is undefined.

**Pseudocode:**

```python
def validate_and_aggregate(records):
    successful_records = []
    failed_records = []
    total_successes = 0
    
    for record in records:
        # Validation logic (e.g., check if token count matches expected, check memory, etc.)
        if record['status'] == 'VALID':
            successful_records.append(record)
            total_successes += 1
        else:
            failed_records.append(record)
            total_successes = 0 # Reset counter for this run to prevent double-counting

    # Compute Median
    if len(successful_records) < 2:
        median = "Undefined (less than 2 successful runs)"
    else:
        sorted_records = sorted(successful_records, key=lambda r: r['token_count'])
        # Sort by token count descending
        sorted_records.sort(reverse=True)
        
        if len(sorted_records) % 2 == 1:
            median = sorted_records[len(sorted_records)//2]['token_count']
        else:
            median = (sorted_records[len(sorted_records)//2 - 1]['token_count'] + 
                       sorted_records[len(sorted_records)//2]['token_count']) / 2)
            
    return {
        'successful': successful_records,
        'failed': failed_records,
        'total_successes': total_successes,
        'median_token_count': median
    }
```

**Reporting Results:**
*   **If fewer than two runs succeed:** Report the result as `"Median is undefined (less than 2 successful runs)"`.
*   **If more than two runs succeed:** Report the `median_token_count` and the count of successful runs.
*   **If all runs fail:** Report the count of failed runs.
*   **For the failed run:** The record must remain in the stream to allow users to investigate why it failed.

### Task 4 — Validity Audit
