### Explanation of the One-Pass O(1) Algorithm

1.  **Parsing**: We iterate through `lines` once. If a line is not a string, we skip it. This handles the non-string item requirement.
2.  **Event Check**: We check `tokens[0]` for the string `"decode"`. If not found, we skip.
3.  **Tokenize**: We split the line by whitespace to get tokens.
4.  **Value Extraction**: We extract `tokens[1]` as the tps value string.
5.  **Validation Loop**: We iterate through tokens again. We extract the tps key-value pair from `tokens[1]`.
    *   **Finite Positive Check**: We convert the string to a float. We check if it is `finite`, is strictly positive (`> 0`), and is a valid Python float.
    *   **Duplicate Key Check**: We create a dictionary of key-value pairs from `tokens[1]`. We check if the number of keys exceeds 1. If so, we skip that line.
    *   **Other Keys Check**: We extract the tps key-value pair from `tokens[2]` (skipping any extra keys). We check if the number of keys exceeds 1. If so, we skip that line.
    *   **Other Event Check**: We check if `tokens[0]` is `"decode"`. If not, we skip.
    *   **Other Keys Check**: We extract the tps key-value pair from `tokens[2]` (skipping any extra keys). We check if the number of keys exceeds 1. If so, we skip.
    *   **Key Existence Check**: We check if `tokens[1]` is not empty. If not, we skip.
6.  **Accumulate**: If all checks pass, we append the tuple `(token_index, tps_val, token_index)` to our valid records list.
