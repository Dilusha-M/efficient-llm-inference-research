```python
import math
from typing import Iterable, Dict, Optional, Any

def summarize_decode_speeds(lines: Iterable[Any]) -> Dict[str, Optional[float]]:
    """
    Summarizes the decode speeds from a stream of log lines.
    
    Processes records in a single pass with O(1) auxiliary space.
    """
    count = 0
    min_tps = float('inf')
    max_tps = float('-inf')
    total_tps = 0.0

    for line in lines:
        # Ignore non-string items
        if not isinstance(line, str):
            continue

        # Tokenize by whitespace
        tokens = line.split()
        if not tokens:
            continue

        # Parse key-value pairs into a dictionary to handle duplicates
        # and ensure we only capture the correct event/tps values.
        record = {}
        is_malformed = False
        
        for token in tokens:
            if '=' not in token:
                continue
            
            key, val = token.split('=', 1)
            # If a key is repeated, the line is malformed per requirements
            if key in record:
                is_malformed = True
                break
            record[key] = val

        if is_malformed:
            continue

        # Validation Logic:
        # 1. Must contain event=decode
        # 2. Must contain tps=<value>
        # 3. Value must be finite, > 0, and a valid float
        if record.get("event") == "decode" and "tps" in record:
            try:
                tps_val = float(record["tps"])
                
                # Check for finite, strictly positive, and non-zero
                if math.isfinite(tps_val) and tps_val > 0:
                    count += 1
                    total_tps += tps_val
                    if tps_val < min_tps:
                        min_tps = tps_val
                    if tps_val > max_tps:
                        max_tps = tps_val
                else:
                    # Covers nan, inf, and <= 0
                    continue
            except ValueError:
                # Handles non-numeric strings
                continue

    return {
        "count": count,
        "min_tps": min_tps if count > 0 else None,
        "max_tps": max_tps if count > 0 else None,
        "avg_tps": round(total_tps / count, 3) if count > 0 else None
    }
```

### Technical Explanations

**Why naive substring matching fails:**
1. **Duplicate Keys:** If a line contains `event=decode tps=10.0 tps=50.0`, a substring search for `tps=` might find the first occurrence and treat it as valid, whereas the requirements state duplicate keys with conflicting values make the record malformed.
2. **Partial Matches:** A substring search for `event=decode` might match `event=decode_metadata` or `not_event=decode`, leading to false positives.
3. **Contextual Integrity:** Parsing into a dictionary ensures that the `tps` value belongs to the specific record being evaluated and allows for easy validation of the "exactly one unique key" constraint.

**Empty-result policy:**
If no valid records are found, the count is `0` and the `min`, `max`, and `avg` values are `None`. This is the standard production approach to differentiate between a calculation resulting in zero (e.g., an average of zero) and the absence of data, preventing `ZeroDivisionError` and providing a clear API for downstream consumers.
