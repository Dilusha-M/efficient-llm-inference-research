```python
import math

def summarize_decode_speeds(lines):
    """
    Summarizes decode speeds from an iterable of log strings.
    
    Complexity:
    - Time: O(N) where N is the total number of characters in the input.
    - Space: O(1) extra space (excluding the input iterable).
    """
    count = 0
    min_tps = float('inf')
    max_tps = float('-inf')
    sum_tps = 0.0

    for line in lines:
        if not isinstance(line, str):
            continue
        
        # Tokenize by whitespace
        tokens = line.split()
        if not tokens:
            continue
            
        # Parse key-value pairs into a dictionary
        # We use a dict to detect duplicate keys and ensure unique values
        record = {}
        is_valid_line = True
        
        for token in tokens:
            if '=' not in token:
                continue
            key, val = token.split('=', 1)
            
            # Rule: Duplicate keys with conflicting values (or same values) are malformed
            if key in record:
                is_valid_line = False
                break
            record[key] = val
            
        if not is_valid_line:
            continue

        # Validation logic
        if record.get("event") != "decode":
            continue
            
        tps_str = record.get("tps")
        if tps_str is None:
            continue
            
        try:
            tps = float(tps_str)
            # Rule: Must be finite, strictly positive, and not NaN
            if not math.isfinite(tps) or tps <= 0:
                continue
        except ValueError:
            continue

        # Update metrics
        count += 1
        if tps < min_tps:
            min_tps = tps
        if tps > max_tps:
            max_tps = tps
        sum_tps += tps

    # Finalize results
    if count == 0:
        return {
            "count": 0,
            "min_tps": None,
            "max_tps": None,
            "avg_tps": None
        }

    return {
        "count": count,
        "min_tps": min_tps,
        "max_tps": max_tps,
        "avg_tps": round(sum_tps / count, 3)
    }
```

### Technical Explanations

#### Why naive substring matching fails:
1. **False Positives on Event Types**: A naive check like `if "event=decode" in line` would incorrectly validate a line like `event=generate_decode_metadata tps=50.0`. The logic must strictly isolate the `event` key.
2. **Key Collision/Ambiguity**: Substring matching cannot distinguish between `tps=50.0` and a different key containing that string (e.g., `old_tps=50.0`).
3. **Duplicate Key Handling**: If a line contains `tps=10.0 tps=20.0`, substring matching might find the first one and consider it valid. The requirement specifies that duplicate keys (even with the same value) make the record malformed. Parsing into a dictionary is the standard way to detect this during a single pass.

#### Empty-Result Policy:
The function returns `None` for `min_tps`, `max_tps`, and `avg_tps` when `count` is 0. This is the standard production pattern to distinguish between a "zero value" (e.g., a speed of 0.0) and "no data available." Returning `0.0` would be mathematically incorrect as the average of an empty set is undefined, and `min/max` of an empty set has no bound.
