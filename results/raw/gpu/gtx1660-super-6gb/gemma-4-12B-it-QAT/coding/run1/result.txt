```python
import math
from typing import Iterable, Dict, Optional, Any

def summarize_decode_speeds(lines: Iterable[Any]) -> Dict[str, Optional[float]]:
    """
    Summarizes TPS (tokens per second) from an iterable of log strings.
    
    Complexity:
    - Time: O(N) where N is the total number of characters in the input.
    - Space: O(1) auxiliary space (excluding the result dictionary).
    """
    count = 0
    min_tps = float('inf')
    max_tps = float('-inf')
    sum_tps = 0.0

    for line in lines:
        # Requirement: Ignore non-string items
        if not isinstance(line, str):
            continue

        # Tokenize by whitespace
        parts = line.split()
        data = {}
        is_valid_decode = False
        
        # Parse key-value pairs
        for part in parts:
            if '=' not in part:
                continue
            key, val = part.split('=', 1)
            
            # Requirement: Handle duplicate keys (conflicting or same)
            if key in data:
                # If key exists, the line is malformed regardless of value
                break
            data[key] = val

        # Requirement: Must contain event=decode and tps=<value>
        if data.get("event") != "decode":
            continue
            
        tps_str = data.get("tps")
        if tps_str is None:
            continue

        try:
            tps_val = float(tps_str)
            
            # Requirement: Finite, strictly positive decimal
            # Note: math.isfinite handles nan and inf
            if math.isfinite(tps_val) and tps_val > 0:
                count += 1
                if tps_val < min_tps:
                    min_tps = tps_val
                if tps_val > max_tps:
                    max_tps = tps_val
                sum_tps += tps_val
        except ValueError:
            # Ignore malformed floats
            continue

    if count == 0:
        return {
            "count": 0,
            "min_tps": None,
            "max_tps": None,
            "avg_tps": None
        }

    return {
        "count": count,
        "min_tps": min_tps,
        "max_tps": max_tps,
        "avg_tps": round(sum_tps / count, 3)
    }
```

### Technical Explanations

**Why Naive Substring Matching Fails:**
1.  **Key Ambiguity:** A simple `if "tps=" in line` check would incorrectly validate a record containing `other_tps=50` or `max_tps=50`. By splitting into tokens and using a dictionary, we ensure we are specifically accessing the `tps` key.
2.  **Duplicate Keys:** Substring matching cannot easily detect if a key appears twice. The requirements specify that a duplicate `tps` key (even with the same value) renders the line malformed. A dictionary-based approach allows us to check `if key in data` before insertion to catch this.
3.  **Event Context:** Substring matching might find `tps=50` in a line where `event=generate`, but the requirements strictly limit valid records to `event=decode`.

**Empty-Result Policy:**
The function returns `None` for `min_tps`, `max_tps`, and `avg_tps` when `count == 0`. This is standard production practice to differentiate between a "zero" value (which is a valid numeric result) and the absence of data (which is a null state). Using `None` prevents the caller from accidentally performing arithmetic on undefined results.
