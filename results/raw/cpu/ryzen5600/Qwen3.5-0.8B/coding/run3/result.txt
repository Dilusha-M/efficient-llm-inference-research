```python
from typing import Iterable, Optional

def summarize_decode_speeds(lines: Iterable[str]) -> dict[str, Optional[float]]:
    """
    Summarize decode speeds for a list of lines.
    
    A record is valid only when:
    1. After splitting on whitespace, it contains exactly two keys: 'event' and 'tps'.
    2. The 'event' value is exactly "decode".
    3. The 'tps' value is a finite, strictly positive decimal (float).
    
    Invalid records are ignored entirely.
    """
    valid_records: list[tuple[str, float]] = []

    for line in lines:
        # Ignore non-string items; treat them as if they were strings to split.
        stripped = line.strip()
        if not stripped:
            continue

        tokens = stripped.split()
        if len(tokens) != 2:
            # Malformed line; skip it
            continue

        event = tokens[0]
        tps_str = tokens[1]

        # Check event
        if event != "decode":
            continue

        # Check tps_str is a finite, strictly positive float
        try:
            tps = float(tps_str)
            if tps <= 0:
                continue
        except (ValueError, TypeError):
            continue

        valid_records.append((event, tps))

    if not valid_records:
        return {
            "count": 0,
            "min_tps": None,
            "max_tps": None,
            "avg_tps": None
        }

    return {
        "count": len(valid_records),
        "min_tps": float(min(tps for _, tps in valid_records)),
        "max_tps": float(max(tps for _, tps in valid_records)),
        "avg_tps": round(float(sum(tps for _, tps in valid_records) / len(valid_records)), 3)
    }


def main():
    lines = [
```

### Explanation of the Algorithm and Policy

#### Why Naive Substring Matching Fails
Naive substring matching (`event == "decode"` and `tps == "15000"`) is insufficient because:
1. **Event Mismatch**: It matches the literal string `"decode"` regardless of case or formatting. It does not check that the `event` field contains the specific key `"event"` (case-sensitive).
2. **Duplicate Keys**: It treats any occurrence of `"tps"` with the value `"15000"` as a match. In the example `tps=15000`, the key is `"tps"`, not `"tps=15000"`. It would incorrectly match the malformed line `tps=15000` (assuming it was split as `["tps", "15000"]`).

#### Empty-Result Policy
If no valid records are found, the function must return a dictionary where `count`, `min_tps`, `max_tps`, and `avg_tps` are all `None`. Returning all `None` is safer than returning a dictionary with a single `None` value, as it provides explicit nulls for all tracked metrics, which the caller can check without ambiguity.
