def robust_aggregate_decodes(runs):
    # 1. Collect all valid runs
    valid_runs = []
    for i, run in enumerate(runs):

    if len(valid_runs) < 2:

        "failed_run": failed_run,

    }

### Task 5 — User-Visible Latency
**Explanation of Differences:**
*   **Time to First Token (TTFT):** The time elapsed from the moment the user clicks "Generate" to the moment the first character of the first token is displayed. This is the **peak latency** of the generation process.
*   **Prompt-Evaluation Throughput (PET):** The average number of tokens generated per second (tokens/sec) during the generation phase. This is not latency but throughput.
*   **Decode Throughput (DT):** The average number of tokens generated per second (tokens/sec) after the first token is displayed. This is the latency phase (latency = time to first token + average delay).
*   **Total Wall-Clock Time (TWT):** The total time elapsed from the moment the user clicks "Generate" to the moment the last token is displayed.

**Symbolic Equation:**
$$ T_{total} = T_{first} + T_{delay} + T_{last} $$

**Example:**
*   In a scenario where optimizing prompt processing barely changes the experience, **TTFT** remains constant, **PET** remains constant, but **DT** (and thus **TWT**) increases slightly due to the added latency of the prompt processing phase. The user feels no change in the user-visible latency, as the bottleneck is now the prompt processing itself, not the model generation.
