def summarize_decode_speeds(lines):
    """
    Summarize decode speed metrics from a list of strings.
    
    A valid record must:
      - Contain 'event=decode'
      - Contain 'tps=<value>' where value is a finite, strictly positive float
      - Not have conflicting duplicate tps with a different value
      - Not contain non-finite floats (nan, inf, -inf)
      - Not contain zero or negative values for tps
    
    Returns a dict with:
      - count: int (number of valid records)
      - min_tps: float | None
      - max_tps: float | None
      - avg_tps: float | None (rounded to 3 decimals)
    
    This implementation uses a one-pass O(1) extra-space algorithm.
    
    Example:
        lines = [
            "event=decode tps=123.456",
            "event=decode tps=234.567",
            "event=other tps=999.000",
            "event=decode",
            "event=decode tps=nan",
            "event=decode tps=-1",
            "event=decode tps=0",
            "event=decode tps=inf",
            "event=decode",
            "event=decode tps=100.000",
            "event=decode tps=100.000",
        ]
        # Valid tps: 123.456, 234.567, 100.000, 100.000 (ignored as duplicate)
        # Result: count=3, min=123.456, max=234.567, avg=176.44857142857143 -> 176.449
    """
    
    # One-pass O(1) extra space:
    #   - We maintain a set of seen tps values as we iterate through lines
    #   - We track counts, min, max, and current sum
    #   - We ignore non-string items and skip malformed lines entirely
    #   - No auxiliary data structures beyond these variables
    
    seen_tps = set()
    count = 0
    min_tps = None
    max_tps = None
    tps_sum = 0.0
    
    for line in lines:
        # Normalize: strip whitespace around the entire line
        normalized_line = line.strip()
        
        # Ignore non-string items
        if not isinstance(normalized_line, str):
            continue
            
        # Parse key=value pairs
        parts = normalized_line.split('=', 1)
        if len(parts) < 2:
            continue
            
        key, value_str = parts
        
        # Only process if key is 'tps'
        if key != 'tps':
            continue
            
        try:
            tps_value = float(value_str)
        except (ValueError, OverflowError):
            continue  # Skip malformed float conversions
        
        # Validate constraints:
        #   - Strictly positive
        #   - Finite (not nan, inf, -inf)
        #   - Not zero
        #   - Not negative
        if tps_value <= 0 or tps_value == float('inf') or tps_value == float('-inf') or tps_value == float('nan'):
            continue
        
        # Check for duplicates (only with same value)
        if tps_value in seen_tps:
            continue
        
        # Valid record found
        seen_tps.add(tps_value)
        count += 1
        tps_sum += tps_value
        
        # Update min/max
        if min_tps is None or tps_value < min_tps:
            min_tps = tps_value
        if max_tps is None or tps_value > max_tps:
            max_tps = tps_value
    
    # Compute average
    if count > 0:
        avg_tps = round(tps_sum / count, 3)
    else:
        avg_tps = None
    
    return {
        'count': count,
        'min_tps': min_tps,
        'max_tps': max_tps,
        'avg_tps': avg_tps
    }

3. **Whitespace issues**: Without explicit line stripping, whitespace around values could cause float parsing errors (e.g., `tps=100.000 ` vs `tps=100.000`).

- When no valid records are found (empty result), we return `None` for all numeric fields rather than arbitrary defaults. This provides clear signals to callers that the dataset was processed but yielded no usable metrics, which is more informative than a guessed value like `0.0`.
