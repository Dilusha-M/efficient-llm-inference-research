### Task 3 — Robust Aggregation

**Pseudocode for Median Calculation**
```python
def calculate_median_speeds(decode_speeds, failed_run_info):
    valid_runs = []
    
    # 1. Validate records
    for i, speed in enumerate(decode_speeds):
        # Check if run is valid based on telemetry
        if i == len(decode_speeds) - 1:
            # Last run is a failure; mark others as valid
            valid_runs.append(speed)
        else:
            # Intermediate runs are valid
            valid_runs.append(speed)
    
    # 2. Compute median without treating failure as zero
    if not valid_runs:
        raise ValueError("No valid runs found. Only the last run was reported as failed.")
    
    # Median calculation
    sorted_runs = sorted(valid_runs)
    n = len(sorted_runs)
    if n % 2 == 1:
        median = sorted_runs[n // 2]
    else:
        median = (sorted_runs[n // 2 - 1] + sorted_runs[n // 2]) / 2.0
    
    return median
```
*Note:* This logic explicitly includes the failed run's speed in the "valid" list (as the only failure) or discards it entirely. It does not treat the failure as a zero value.

### Task 5 — User-visible Latency

**Difference Between Metrics**
*   **Time to First Token (TTFT):** The wall-clock time from the start of the prompt to the generation of the first token. This is the user's direct, tangible latency.
*   **Prompt-Evaluation Throughput:** The rate at which the system processes the prompt (e.g., parsing, tokenizing) without waiting for the model. This is internal efficiency, invisible to the user.
*   **Decode Throughput:** The rate at which the model generates tokens (e.g., 200 tokens/sec). This determines the "length" of the response, not the start time.
*   **Total Wall-Clock Time:** The sum of TTFT, Prompt-Evaluation Time, and Decode Time. This is the total time the user sees from prompt input to completion.

**Symbolic Equation**
$$ \text{Total Time} = \text{TTFT} + \text{PromptEvalTime} + \text{DecodeTime} $$
*(Where $\text{DecodeTime} = \frac{\text{Generated Tokens}}{\text{Decode Throughput}}$)*

**Example of Minimal Impact**
*   **Scenario:** You have a 2,000-token prompt and 200 generated tokens.
*   **Optimization:** You optimize the prompt processing (e.g., caching the query, optimizing tokenization) so it takes 0.5ms, but the model response time remains constant at 100ms.
*   **Result:** The **User Experience** (TTFT and total time) barely changes because the optimization happened in the "Prompt-Evaluation Time" phase, which is invisible to the user. The **Decode Throughput** (tokens/sec) might improve slightly, but since the user doesn't know the response duration, they only notice the same speed of generation.
