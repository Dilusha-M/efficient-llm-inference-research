### Task 5 — user-visible latency:
**Explanation:**
*   **Time to First Token:** This is the **latency** of the initial interaction with the user, determined by the network round trip and the time to decode the first token.
*   **Prompt-Evaluation Throughput:** This is the **throughput** of the model while the user is actively typing, representing how fast the system can process the prompt *before* it actually generates output.
*   **Decode Throughput:** This is the **throughput** of the model while the user is actively generating tokens, representing how fast the system can process the generated output.
*   **Total Wall-Clock Time:** This is the sum of the **Time to First Token**, **Prompt-Evaluation Throughput**, and **Decode Throughput**. Symbolically:
    $$ \text{Total Time} = \text{Time to First Token} + \text{Prompt-Evaluation Throughput} + \text{Decode Throughput} $$

**Example:**
If the system is highly optimized, the **Time to First Token** and **Prompt-Evaluation Throughput** might be very low (e.g., 5ms and 10 tokens/s respectively). In this scenario, optimizing the prompt processing (e.g., by adding a small amount of padding or specific formatting) would change the "Time to First Token" or "Prompt-Evaluation Throughput" by at most a few milliseconds, which is negligible to a user's experience.
