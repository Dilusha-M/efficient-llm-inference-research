import math
from typing import Any, Iterable, Dict, Optional

def summarize_decode_speeds(lines: Iterable[Any]) -> Dict[str, Optional[float]]:
    """
    Summarize decode speeds from a stream of key=value lines.
    
    A record is valid if:
    - It is a string.
    - After splitting on whitespace, it contains exactly one 'event=decode' and exactly one 'tps=<value>' key.
    - The 'tps' value is a finite, strictly positive float.
    
    Returns:
        {
            'count': int,
            'min_tps': float or None,
            'max_tps': float or None,
            'avg_tps': float (3 decimals) or None
        }
    """
    count = 0
    min_val = None
    max_val = None
    total = 0.0
    
    for line in lines:
        # Requirement: Do not crash if lines contains a non-string item; ignore that item.
        if not isinstance(line, str):
            continue
        
        tokens = line.split()
        if len(tokens) < 2:
            continue
        
        event_key = None
        tps_value = None
        
        for token in tokens:
            if '=' not in token:
                continue
            
            key, val = token.split('=', 1)
            
            if key == 'event' and val == 'decode':
                event_key = True
            elif key == 'event' and val != 'decode':
                # Malformed: duplicate 'event' key with conflicting value
                continue
            elif key == 'tps':
                # Check for duplicate tps key (conflicting value)
                if tps_value is not None:
                    # Malformed: duplicate key with different value (or even same, treated as malformed per spec "Treat a duplicate tps key with the same value as malformed too")
                    continue
                
                try:
                    tps_float = float(val)
                except ValueError:
                    # Malformed float
                    continue
                
                if not math.isfinite(tps_float) or tps_float <= 0:
                    continue
                
                tps_value = tps_float
        
        # Valid record check: must have both event=decode and tps
        if event_key is True and tps_value is not None:
            count += 1
            total += tps_value
            
            if min_val is None or tps_value < min_val:
                min_val = tps_value
            if max_val is None or tps_value > max_val:
                max_val = tps_value
    
    if count == 0:
        return {
            'count': count,
            'min_tps': None,
            'max_tps': None,
            'avg_tps': None
        }
    
    avg_tps = round(total / count, 3)
    
    return {
        'count': count,
        'min_tps': min_val,
        'max_tps': max_val,
        'avg_tps': avg_tps
    }

### Explanation of Logic and Edge Cases

#### Why Naive Substring Matching Fails
Naive substring matching (e.g., `if 'event=decode' in line and 'tps=' in line`) is susceptible to:
1. **Wrong Event Matching**: A line like `event=other tps=100` would pass the substring check for `event=decode` if the string `event=decode` appeared elsewhere (e.g., in a comment or concatenated string), or if the parser checks for `event` and `decode` separately rather than the exact key `event=decode`. More critically, a line like `event=decode tps=100 event=decode` contains the substring but represents a malformed duplicate key.
2. **Malformed Duplicate Keys**: A naive check might find `event=decode` twice and `tps=` twice but fail to detect that having two `tps` keys is invalid. It might just take the first or last value, leading to incorrect `min/max` or `count`.
3. **Whitespace Sensitivity**: `split()` handles all whitespace (spaces, tabs, newlines) uniformly, whereas naive `split()` with arguments or manual parsing might fail on inconsistent spacing.

#### Empty-Result Policy
The function returns a dictionary with `None` for `min_tps`, `max_tps`, and `avg_tps` when `count` is zero. This avoids division by zero errors and provides clear feedback that no valid data was found, rather than raising an exception or returning 0.0 (which would be semantically incorrect for "no records").

#### One-Pass Algorithm
The function iterates through `lines` once. It maintains `count`, `total`, `min_val`, and `max_val` in O(1) variables. It does not store the input lines or all records, satisfying the O(1) extra space requirement (excluding the input iterable itself).
