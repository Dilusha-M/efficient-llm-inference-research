```python
from typing import Iterable, Dict, Any
import math
import re

def summarize_decode_speeds(lines: Iterable[str]) -> Dict[str, Any]:
    """
    Summarize decode speed metrics from a stream of lines.
    
    A record is valid only when:
    - After stripping whitespace, the line contains 'event=decode'
    - It contains a 'tps' key with a finite, strictly positive float value
    - No duplicate 'tps' keys with conflicting values
    
    Returns a dict with keys: count, min_tps, max_tps, avg_tps
    All values are rounded to 3 decimal places for avg_tps.
    Returns None for min_tps, max_tps, avg_tps when no valid records exist.
    """
    
    # Initialize tracking variables
    tps_values = []  # list of valid tps values (floats)
    has_valid_record = False
    
    # Process each line
    for line in lines:
        if not isinstance(line, str):
            # Non-string item: ignore silently
            continue
        
        # Strip whitespace and check for event=decode
        stripped = line.strip()
        if stripped.startswith("event=decode"):
            # Extract tps value
            match = re.search(r'tps=(\d+\.?\d*)', stripped)
            if not match:
                # No tps field found -> malformed
                continue
            
            tps_str = match.group(1)
            try:
                tps = float(tps_str)
            except ValueError:
                # Invalid float format -> malformed
                continue
            
            # Check for valid float conditions:
            # Must be finite (not inf, nan)
            # Must be strictly positive (> 0)
            if math.isinf(tps) or math.isnan(tps) or tps <= 0:
                # Invalid value -> malformed
                continue
            
            # Record valid tps
            has_valid_record = True
            tps_values.append(tps)
    
    # Compute statistics
    count = len(tps_values)
    
    if count == 0:
        min_tps = None
        max_tps = None
        avg_tps = None
    else:
        min_tps = min(tps_values)
        max_tps = max(tps_values)
        avg_tps = round(sum(tps_values) / count, 3)
    
    return {
        "count": count,
        "min_tps": min_tps,
        "max_tps": max_tps,
        "avg_tps": avg_tps
    }
```

### Explanation of Implementation

**1. Naive Substring Matching Issues:**
The naive approach of checking if `event=decode` exists anywhere in the string would accept invalid records:
- **Wrong event acceptance**: A line like `"event=wrong_type, tps=100"` would pass the substring check but fail validation since `wrong_type` is not `decode`.
- **Duplicate key handling**: The spec requires ignoring lines with duplicate `tps` keys with conflicting values. A naive scan might miss checking if a new `tps` value conflicts with existing ones.
- **Whitespace handling**: Naive approaches might not properly handle all whitespace variations or could incorrectly strip non-string items as "empty" lines.

**2. Empty Result Policy:**
When no valid records are found, the function correctly returns `None` for all summary statistics. This is important because:
- Returning `0` for count would be misleading
- Returning `0.0` for average would suggest activity when there's actually no data
- Returning `None` properly indicates "no data available" rather than "no data generated"

**3. One-Pass Algorithm:**
The implementation processes the iterable in a single pass through the lines, maintaining only the current line's information and the accumulated statistics. No intermediate lists or complex data structures are stored.
