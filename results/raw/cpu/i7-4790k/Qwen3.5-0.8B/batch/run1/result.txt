**Task 5 — User-visible Latency**
*Assumptions:* 2,000-token prompt (input), 200 generated tokens (output).

*Explanation of Differences:*
*   **Time to First Token (TTFT):** This is the time required to load and process the input prompt to the GPU. It is independent of the generation process. It is measured in milliseconds (ms) and is the most critical metric for user experience, especially for long prompts.
*   **Prompt-Evaluation Throughput:** This refers to the rate at which the system processes the input prompt to generate a token sequence in a single pass. It is measured in tokens per second (tokens/s).
*   **Decode Throughput:** This is the rate at which the system processes the generated token sequence to produce the final output. It is measured in tokens per second (tokens/s).
*   **Total Wall-Clock Time:** The sum of the three phases above (TTFT + Prompt-Evaluation Throughput + Decode Throughput).

*Symbolic Equation:*
$$Total\_Wall\_Clock\_Time = TTFT + Prompt\_Evaluation\_Throughput + Decode\_Throughput$$

*Example of Optimizing Prompt Processing:*
If the **Prompt-Evaluation Throughput** is the limiting factor, optimizing the prompt processing (e.g., using a smaller context window, reducing tokenization overhead, or applying tokenization compression) will reduce the time required to process the input, leading to a faster TTFT and potentially faster overall throughput. Optimizing the output (e.g., using an encoder-decoder architecture with better tokenization) will speed up Decode Throughput, but it will not affect TTFT.

**Summary of User Experience:**
A user who reads a 2,000-token prompt will experience a significant increase in time to first token if the system cannot efficiently load the prompt data. However, if the system is optimized for decoding (e.g., using a high-performance decoder and efficient tokenization), the user will notice a slight reduction in the time to first token, but the overall user experience (completion time) will remain largely identical because the generation process itself is optimized.
